M6 — DevSecOps: Trivy Vulnerability Scanning

Shift-left container security blocking vulnerable software from production

Trivy Gate Configuration
  • Action: aquasecurity/trivy-action in CI pipeline.
  • Scanned Artifacts: Backend & Frontend container images.
  • Severity Filter: HIGH,CRITICAL.
  • Enforcement Rule: exit-code: '1'. Any unresolved high or critical CVE immediately fails the build.
  • Actionable Focus: ignore-unfixed: true blocks deploy only when vendor patches exist.
Written Vulnerability Evaluation
  • Attack Surface Reduction: Minimal base images (python:3.12-slim and Alpine) shrink package count by > 80%.
  • Privilege Escalation Defense: Non-root users (10001 and 101) eliminate kernel escape vectors.
  • Production Assurance: No untested or vulnerable container can ever be published to GHCR.
